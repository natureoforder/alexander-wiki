# Christopher Alexander Wiki

A concept-first guide to Christopher Alexander, with collections for Living Neighborhoods and A Pattern Language. Start at the [wiki homepage](index.md).

The repository root is the Flowershow content root. Keep research transcriptions in the separate sources workspace and cite the published edition and chapter or pattern number from wiki pages.

Project scope and dependencies live in the Beads epic `alex-88s`. Run `bd show alex-88s` from a bootstrapped clone.

## Flowershow preview

[Open the preview](https://alexander-wiki-preview-rufuspollock.flowershow.me). The preview uses the Flowershow CLI under the `rufuspollock` account. Its local publishing directory is `~/.cache/alexander-wiki-flowershow-preview/`. Sync the reader-facing files and assets there before running `fl --yes ~/.cache/alexander-wiki-flowershow-preview`. Keep the directory’s `.flowershow` binding for subsequent updates.

## Cover reference

The homepage shows the dust jacket of Christopher Alexander and colleagues’ *A Pattern Language* (Oxford University Press, 1977, ISBN 9780195019193). The jacket image is the reference for the beige paper, dark title and coral printing ink. The cover lettering is approximated with a bold Times-style serif. [Jacket image](https://images-na.ssl-images-amazon.com/images/P/0195019199.01.L.jpg)

For a passage citation, put a numbered Markdown footnote such as `[^1]` beside the passage and its definition, `[^1]: Citation`, after the article. Short notes numbered 1–9 can sit beside their paragraphs on wide screens. Longer sequences continue as endnotes.
