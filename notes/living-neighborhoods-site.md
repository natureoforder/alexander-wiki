# Using the old Living Neighborhoods site

I used livingneighborhoods.org a lot, and it was terrible to use. It was built from frames and inline JavaScript, with navigation that followed the authors' working folders rather than what a reader needs, and I got completely lost in it. Yet the material in it is really useful: the generative code for neighbourhoods, step-by-step unfoldings, and accounts of Eishin, Mexicali, West Dean and Fresno.

So the point of bringing it into this wiki is not only to tidy the HTML. It is to re-route the material: lay it out so someone can follow the generative process phase by phase, find the worked examples, and pull what they need into building a room, a house or a hamlet.
